Syntax & default fields

field:value match · field:"some words" phrase · views:[100 TO 500] range · last:15m time window.

Default fields: title, created_by, tags, status, views, published_at, @timestamp.

Aliases: author → created_by, tag → tags, ts → @timestamp. Fields depend on the server's configured rules; relative time uses its configured time field.
